GestionaHub - Proyecto completo con todas las mejoras (10/11/2026)
==================================================================

Esta carpeta es el proyecto entero, sin vendor ni archivos temporales.
Incluye: Bloque 1 (repartidores, proveedores, demo, limpieza de textos),
Bloque 2 (prospeccion IA, QR de mesas, cocina, sucursales), Bloque 3 (landing:
SEO con IA, popup, chatbot), reportes GEST-40/41, fidelizacion y correcciones.

ANTES DE COPIAR SOBRE TU PROYECTO
- Compara con tu repositorio (git diff) para no perder cambios que hayas hecho tu.
- No copies .env: usa tu .env y agrega las variables de abajo.

PASOS (Docker, una linea a la vez)
1. Copia el contenido de esta carpeta a tu proyecto.
2. docker compose exec app composer install
3. docker compose exec app php artisan migrate
4. docker compose exec app php artisan storage:link
5. docker compose exec app php artisan optimize:clear
6. docker compose exec app php artisan db:seed --class=DemoDataSeeder   (solo local)
7. docker compose exec app php artisan test

NOVEDADES 12 NOV (GEST-101 a GEST-112): TIENDA ONLINE
- Tienda nueva en /tienda/tu-negocio: buscador, categorías, destacados, banners, ficha del producto,
  carrito que se guarda en el celular y pago en 3 pasos (datos y entrega, pago, confirmación).
- Variantes (1/4, entero…) y venta por kilo (250 g, 500 g, 1 kg o peso libre).
- Abierto/cerrado según tu horario; cuando está cerrado el cliente programa su pedido.
- Envío por zona, pedido mínimo, envío gratis desde, cupones y pago con puntos.
- El pedido entra a Pedidos (canal Tienda online), descuenta stock, crea el cliente y avisa por WhatsApp.
- Peso real al despachar: abre el pedido en Pedidos y escribe el peso; el total se recalcula.
- Editor en Tienda pública → Editar tienda: banners, avisos, destacados, pagos (Yape/Plin con QR),
  redes, términos, políticas, preguntas frecuentes, cupones y Google (SEO).
- SEO: enlace propio por producto, Open Graph, datos para Google, sitemap.xml y robots.txt.

LAS 2 TAREAS QUE FALTABAN DEL TABLERO
- GEST-57 Membresías (menú Membresías): creas planes semanales, quincenales, mensuales o anuales.
  Tus clientes se suscriben en /planes/tu-slug (botón "Ver página de planes") o los inscribes tú.
  Cada cliente tiene su enlace (/membresia/código) para pagar con Yape/Plin (sube la captura) o tarjeta (Mercado Pago).
  Cada día a las 8:30 se crea el cobro del siguiente periodo y se avisa por WhatsApp (si está conectado);
  si pasan 3 días sin pagar, queda vencida. Migración nueva: 2026_11_12_280000_membresias_clientes.
- GEST-62 API de pedidos (menú Cuenta → API y conexiones): creas y revocas tokens, ves ejemplos para tu programador
  (ver, crear y cambiar estado de pedidos en /api/v1/pedidos, 60 llamadas por minuto) y, si quieres,
  una dirección https que recibe un aviso firmado cada vez que un pedido cambia de estado.
- Tarjeta dentro de la tienda: en Tienda → Contenido → Pagos y redes pega también la "Public Key" de Mercado Pago.
  Con ella, el cliente paga con tarjeta en la misma página del pedido (y de su membresía), sin salir de tu tienda.
  Sin la Public Key sigue funcionando el botón que lleva a la página de Mercado Pago.
